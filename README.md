Container Orchestration with Kubernetes (K8s)

This project demonstrates container orchestration using **Kubernetes** on a local cluster via **Minikube**. A simple Python Flask web app is dockerized, pushed to DockerHub, and deployed using Kubernetes manifests.

## Tech Stack
- Python (Flask)
- Docker
- Kubernetes (Minikube)
- DockerHub
- kubectl
- YAML

## Features
- Dockerize and deploy a Flask app
- Push image to DockerHub
- Deploy to Kubernetes with a YAML-based Deployment
- Expose app using NodePort Service
- Test and manage using kubectl
